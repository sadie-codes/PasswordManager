What does Password Manager do?
----------------------------------------------------
Password manager provides a quick way to store your passwords for various websites directly through your terminal. You can add, delete, edit, and find passwords as you like!
The application allows you to create a random strong password or create your own! This was my first ever personal project with Python and is useful for local password storage.
<br>

How do I use it?
---------------------------------------------------
Make sure you have the latest version of Git and Python installed. <br>
Type the following in the terminal: <br>
git clone https://github.com/sadie-codes/PasswordManager.git <br>
py main.py
